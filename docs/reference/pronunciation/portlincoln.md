# Port Lincoln (Magic FM 89.9) Pronunciation Guide

Locally-correct pronunciations for Port Lincoln and the Eyre Peninsula region served by Magic FM 89.9 (5CCC). These feed the station's eleven_v3 alias pronunciation dictionary. Every respelling is plain ASCII; the operator should audition each in the ElevenLabs studio before going to air.

## How to read this
Alias respellings only (v3 ignores phoneme); each replaces only the proper-noun token; audition before air.
