# Adelaide (KIIS 102.3) Pronunciation Guide

Locally-correct pronunciations for Greater Adelaide traffic reads on KIIS 102.3, with ElevenLabs v3 alias respellings. Adelaide's names are a mix of Kaurna/Indigenous, German (Prussian Lutheran), and British colonial — the German and Aboriginal-derived names are where TTS most often gets it wrong. Each entry should be auditioned in the ElevenLabs studio before going to air.

## How to read this

Alias respellings only (v3 ignores phoneme/IPA); each replaces only the proper-noun token; audition before air.
