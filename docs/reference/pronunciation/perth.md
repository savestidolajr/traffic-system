# Perth (Gold 96FM) Pronunciation Guide

Locally-correct pronunciations for Greater Perth road, suburb, and landmark names that a generic TTS voice gets wrong. This reference feeds the Gold 96FM ARN traffic bulletin's ElevenLabs eleven_v3 alias pronunciation dictionary. Every alias respelling is plain ASCII for direct use as an eleven_v3 ALIAS rule; each replaces only the proper-noun token (Road/Freeway/Highway stay untouched). An operator should audition each respelling in the ElevenLabs studio before airing.

## How to read this
Alias respellings only (eleven_v3 ignores IPA); each replaces only the proper-noun token; audition before air.
