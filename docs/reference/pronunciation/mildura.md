# Mildura (River 1467) Pronunciation Guide

Locally-correct pronunciations for Mildura and Sunraysia traffic reads on River 1467, with ElevenLabs v3 alias respellings. The Mildura area is rich in Latji Latji and Millewa-Mallee Aboriginal-derived place names — these plus the Mallee highway corridor towns are where TTS most often gets it wrong. Each entry should be auditioned in the ElevenLabs studio before going to air.

## How to read this

Alias respellings only (v3 ignores phoneme/IPA); each replaces only the proper-noun token; audition before air.
